# climbing-performance-econometrics
OLS regression model predicting climber performance level based on physical and strength metrics in R

Building a multiple linear regression model to predict the maximum level. Performing stepwise elimination of insignificant variables (controlled via ANOVA tests and AIC/BIC criteria), full model diagnostic checks (residual normality, homoscedasticity, no autocorrelation, VIF multicollinearity), and Box-Cox transformation analysis.
